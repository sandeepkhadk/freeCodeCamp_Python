## 🚀 Getting Started

### Prerequisites

- Python **3.8+** installed — [Download here](https://www.python.org/downloads/)
- No external libraries required — all scripts use the Python standard library

### Clone the Repository

```bash
git clone https://github.com/sandeepkhadk/freeCodeCamp_Python.git
cd freeCodeCamp_Python
```

### Run Any Script

```bash
python quick_sort.py
python linked_list.py
python tower_of_hanoi.py
# ... and so on
```
